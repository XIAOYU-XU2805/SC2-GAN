SC2-GAN

Official implementation of "Segmentation-Guided and Attention-Enhanced GAN for SAR Image Restoration Under Multi-Type Interference".

SC2-GAN is designed for the restoration of SAR images contaminated by multiple types of interference. This repository provides the source code, dataset, and trained model.

The repository contains the following files:

1. code.zip: Source code.
2. data1.zip–data7.zip: Seven parts of the dataset.
3. netG_epoch_1_0_0_29.pth: Trained model weights of SC2-GAN.

Please download and extract data1.zip–data8.zip before running the code.
After downloading the repository, please extract the source code.
The trained model is provided as: netG_epoch_1_0_0_29.pth
The implementation is based on Python and PyTorch.
